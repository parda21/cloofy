<kbd>Ctrl</kbd> <kbd>K</kbd> opens a command palette for every action and playlist, <kbd>?</kbd> lists all keys, and the hint bar at the bottom shows what works on the current page.

![The command palette open over Home, listing actions with their keys](/screenshots/palette.webp)

## Shortcuts

| Key | Action |
| --- | --- |
| <kbd>space</kbd> | Play or pause |
| <kbd>[</kbd> <kbd>]</kbd> | Previous, next track |
| <kbd>⇧</kbd> <kbd>←</kbd> <kbd>→</kbd> | Seek 5 seconds |
| <kbd>+</kbd> <kbd>-</kbd> | Volume |
| <kbd>s</kbd> <kbd>r</kbd> | Shuffle, repeat |
| <kbd>1</kbd> <kbd>/</kbd> <kbd>3</kbd> | Home, search, your library |
| <kbd>S</kbd> | Switch between Spotify and YouTube Music |
| <kbd>enter</kbd> | Open or play the selection |
| <kbd>esc</kbd> | Back |
| <kbd>f</kbd> | Like the song, or save the album or playlist |
| <kbd>F</kbd> | Follow the artist |
| <kbd>q</kbd> <kbd>a</kbd> | Add to queue, add to a playlist |
| <kbd>.</kbd> | Actions for the selection |
| <kbd>z</kbd> | Now playing and lyrics |
| <kbd>Q</kbd> | Queue |
| <kbd>d</kbd> | Devices, on Spotify |
| <kbd>D</kbd> | Start the DJ on Spotify; while it plays, ask it for something |
| <kbd>X</kbd> | Crossfade, on Spotify |
| <kbd>,</kbd> | Settings |
| <kbd>U</kbd> | Update cloofy |
| <kbd>Ctrl</kbd> <kbd>K</kbd> | Command palette |
| <kbd>?</kbd> | All shortcuts |
| <kbd>Ctrl</kbd> <kbd>C</kbd> | Quit |

## Mouse

Everything works with the mouse too: click to open and play, hover, scroll, drag the seek and volume bars, and right-click for the actions of a song, an album or a playlist.

## Now playing

<kbd>z</kbd> opens the track in full: a large cover, and lyrics that follow the song line by line.

![The now-playing view: a large album cover on the left, synced lyrics on the right with the current line highlighted](/screenshots/nowplaying.webp)

## The queue

<kbd>Q</kbd>, the queue button next to the volume or the command palette shows what plays next, as in Spotify's apps: the song playing now, the songs you queued under **Next in queue**, and the rest of the playlist or album under **Next from**. <kbd>enter</kbd> or a double click skips ahead to a song, and <kbd>Delete</kbd> or its menu takes a song you queued out again.
