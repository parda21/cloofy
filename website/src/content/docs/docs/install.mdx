```sh
curl -fsSL https://cloofy.app/install.sh | bash
```

The installer first asks what you listen to: Spotify, YouTube Music, or both. Each comes as a build of its own, so a YouTube Music install carries no Spotify code, and the other way around. Then it checks your system, puts the latest release in `~/.local/bin`, and walks you through the setup:

- **Spotify:** your Spotify app, its client ID and signing in. See [Spotify](/docs/spotify/).
- **YouTube Music:** mpv, yt-dlp and deno, which it offers to install with your package manager, and an optional sign-in. See [YouTube Music](/docs/youtube-music/).
- **[Omarchy](https://omarchy.org):** cloofy's bar widget, theme, menu entries and launcher. See [Omarchy](/docs/omarchy/).

Run it again to switch between the builds; your settings and sign-ins stay. cloofy offers new releases itself, see [Updates](/docs/updates/).

## Installer options

Options go after `bash -s --`:

```sh
curl -fsSL https://cloofy.app/install.sh | bash -s -- --service ytmusic
```

| Option | What it does |
| --- | --- |
| `--service S` | Installs `spotify`, `ytmusic` or `both` without asking about it |
| `--yes` | Asks nothing: the services you have, or Spotify the first time; sign in later |
| `--uninstall` | Removes cloofy, its entry in the app menu and its Omarchy setup, and its settings and sign-ins if you want |

`CLOOFY_INSTALL_DIR` puts the binary somewhere else than `~/.local/bin`, and `CLOOFY_VERSION` installs a release such as `v0.5.0` instead of the latest.

## Package managers

Package managers have the same three builds:

| | Spotify | YouTube Music | Both |
| --- | --- | --- | --- |
| [Homebrew](https://brew.sh), macOS and Linux | `cloofy` | `cloofy-ytmusic` | `cloofy-full` |
| [mise](https://mise.jdx.dev), anywhere | `matching=spotify` | `matching=ytmusic` | `matching=full` |
| Arch Linux | `cloofy-bin` | `cloofy-ytmusic-bin` | `cloofy-full-bin` |

Homebrew's and Arch's YouTube Music packages bring mpv, yt-dlp and deno along; with mise, install those yourself. Each package replaces the others. Installed with a package manager, go through the setup of [Spotify](/docs/spotify/) or [YouTube Music](/docs/youtube-music/) yourself. The package manager keeps cloofy up to date.

## Building from source

On platforms without a prebuilt binary, the installer builds cloofy with cargo, with only the services you picked. To do that yourself (Rust 1.88 or newer), name them as features; without any, you get both:

```sh
cargo install --git https://github.com/parda21/cloofy --locked cloofy --no-default-features --features ytmusic
```

On Linux the Spotify build needs the ALSA and PulseAudio headers:

| Distro | Packages |
| --- | --- |
| Debian, Ubuntu | `libasound2-dev libpulse-dev pkg-config` |
| Fedora | `alsa-lib-devel pulseaudio-libs-devel` |
| Arch | `alsa-lib libpulse` |

YouTube Music needs no headers to build, and [mpv](https://mpv.io), [yt-dlp](https://github.com/yt-dlp/yt-dlp) (2025.11.12 or newer) and [deno](https://deno.com) to play.

## Uninstall

```sh
curl -fsSL https://cloofy.app/install.sh | bash -s -- --uninstall
```

It takes out cloofy's Omarchy setup first, then the binary, and asks whether your settings, sign-ins and caches go too. Installed with a package manager, remove it there.
